# 微信AI「页面接力(handoff)」官方评测文件说明

本目录下的 `agent-eval-cases.json` 是「31度AI定制」小程序接入微信AI「页面接力(handoff)」基建的官方评测用例文件，用于微信开发者工具评测插件评测 Agent 的意图识别与业务实体抽取能力。

## 一、文件结构

评测文件为合法 JSON，顶层两个字段：

```jsonc
{
  "cases": [           // 自然语言用户请求（意图），共 24 条
    { "intent": "自然语言用户请求" }
  ],
  "entities": [        // 关键业务实体（商品/图案/模板/材质/订单等），共 35 条
    {
      "type": "英文实体类别",      // product / pattern / template / style / material / coin / order / effect 等
      "content": { "关键属性": "值" }, // 实体具体属性键值对
      "source": "原子接口名"        // 实体所属的原子接口
    }
  ]
}
```

约定：
- `cases[].intent` 一律使用真实用户口语，可用「这张照片 / 这张图」指代图片，**禁止**出现「调用 xx 接口」等工程化表述。
- `entities[].source` 只取以下 5 个原子接口名：`startPhotoEngraving`、`generateTextTo25D`、`makeAIStylePhoto`、`makeAICommemorativeCoin`、`queryEngravingStatus`。

## 二、接口覆盖统计表

| 原子接口 | 业务含义 | 用例条数 | 占比 | 对应用例序号 | 实体条数 |
|---|---|---|---|---|---|
| startPhotoEngraving | 照片转2.5D加工包（含AI优化开关） | 6 | 25.0% | 1–6 | 9 |

| makeAIStylePhoto | AI拍照机风格大片（抠图换背景） | 5 | 20.8% | 12–16 | 6 |
| makeAICommemorativeCoin | AI纪念币（环绕文字+金银材质） | 5 | 20.8% | 17–21 | 5 |
| queryEngravingStatus | 查询订单/加工进度 | 3 | 12.5% | 22–24 | 3 |
| **合计** | | **24** | **100%** | — | **35** |

实体多样性覆盖：主题（星空小猫 / 生肖龙 / 卡通头像 / 公司logo / 奖杯）、模板（summer / red / blue / white / gold）、尺寸材质（80x80、50x50、60x80、60mm、50mm、40mm；水晶 / 木质 / 金 / 银 / 红金）、订单号（202606010001、D25060188）。

## 四、使用方式

1. 在微信开发者工具中安装并打开**微信AI评测插件**（Agent 评测 / 页面接力评测）。
2. 选择评测目标为「31度AI定制」小程序的 Agent（即注册了 `wx.onAgentHandoff` 与 5 个原子接口的 Agent）。
3. 上传本目录 `agent-eval-cases.json` 作为评测用例集。
4. 运行评测，校验 Agent 对 24 条用例的意图识别与实体抽取（source 应命中 5 个原子接口），复杂用例需按多步骤 / 多条件正确拆解。

## 五、关联代码（本次接入的基建）

- `src/App.vue`：`onLaunch` 中（`#ifdef MP-WEIXIN`）注册 `wx.onAgentHandoff`，把 `{ pageId, path, query, payload }` 缓存到 `globalData.agentHandoffs`（回调兼容对象/数组两种入参）。
- `src/main.js`：全局页面混入 `app.mixin({ onLoad(){} })`，页面 `onLoad` 时按 `getPageId()`（兜底按路径）命中 handoff 并注入 store。
- `src/stores/agentHandoff.js`：`agentHandoff` pinia store（`setHandoff` / `consumeHandoff` / `clear`）。
- `src/utils/agentHandoff.js`：`getAgentHandoffStore()`、`decodeQuery()`、`buildQuery()` 工具函数。
